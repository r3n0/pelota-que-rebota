# AGENTS.md

Single-file p5.js sketch that bounces a shape around. No build system, no package manager, no tests, no lint, no CI.

## Running

Open `index.html` in a browser. There is nothing to compile, install, or serve. To iterate, reload the page after editing `sketch.js`.

## Structure

- `index.html` — loads p5 (pinned **p5 2.3.3**), **p5.sound 0.4.1**, and **matter-js 0.20.0** from CDNs, then `sketch.js`. Script order matters (see the polyfill note below). There is no bundler and no local dependency install.
- `sketch.js` — the entire sketch, written in p5 **global mode** (`setup()` / `draw()` are globals, not instance mode). Matter.js is read off the global `Matter` (`const { Engine, Composite, ... } = Matter`).
- `.atl/` — auto-generated by the gentle-ai `skill-registry`. Do not hand-edit or commit it.

## Physics (Matter.js)

The bounce is a real rigid-body simulation, not hand-rolled kinematics.

- `setup()` creates an `Engine`, four **static** walls (suelo/techo/izq/der), and one ball body. The walls have `restitution: 0` on purpose: Matter computes `pair.restitution = max(restA, restB)`, so the ball's restitution must drive the bounce.
- `FIGURAS` holds per-shape physics (circle/triangle/square/pentagon: different `restitution`, `friction`, `frictionAir`, `density`). The shape cycles on every wall hit, so `restitution` changes per bounce.
- **Never mutate the world inside `collisionStart`**: the handler only sets `choquePendiente` + `velocidadChoque`. The body swap (remove + create + copy velocity/angularVelocity) runs *after* `Engine.update()` in `resolverChoque()`. A 90 ms cooldown and a 1.5 minimum impact speed avoid corner double-hits and resting jitter.
- Drawing polygons uses `pelota.vertices` (already world-rotated); circles use `circle()`. Do not add an extra `rotate()` or the shape will double-rotate.
- Hover-stop pauses the world by skipping `Engine.update()` when the cursor is over the ball.
- The simulation only steps while p5's `draw()` runs, so a backgrounded browser tab freezes it.

## Audio (p5.sound)

- p5 2.x does **not** bundle p5.sound (unlike 1.x's `lib/addons/`). It is the separate `p5.sound@0.4.1` npm package, a rewrite on top of **Tone.js**.
- API differences vs 1.x tutorials: `Envelope.setRange()` was **removed**. Use `setADSR(a, d, s, r)` and `Envelope.play()` (which triggers attack+release; the `s` value also acts as the note duration). `Oscillator` keeps `start/freq/amp/connect/disconnect`.
- Audio requires a user gesture. The graph is built lazily in `activarAudio()` on the first valid gesture (`mousePressed` / `touchStarted` / `keyPressed`), **never in `setup()`**. Until then `tocarRebote()` returns early and the canvas shows a click hint. Building audio before a gesture creates a suspended `AudioContext` and spams `The AudioContext was not allowed to start`.
- `mousemove` is **not** a user activation in Chrome, so hovering alone never unlocks sound; a click/tap/key is required.
- **Firefox/Safari gotcha**: they don't implement `AudioParam.cancelAndHoldAtTime`, which Tone.js calls from `Oscillator.amp()` / `freq()`. Without the MDN polyfill in `index.html` (loaded **before** p5.sound) the sketch throws `this._param.cancelAndHoldAtTime is not a function`. Do not remove that inline script.

## Conventions

- p5 **2.x** API (note: `circle()`, `windowWidth` / `windowHeight`). Code and comments must stay compatible with p5 2.3.3 — do not assume p5 1.x APIs.
- The canvas is created at `windowWidth` × `windowHeight`. `windowResized()` rebuilds the static walls to match the new size (they are physical bodies, so they do not move on their own) and clamps the ball inside; keep that in sync if wall creation changes.
- Comments and user-facing text are in **Spanish** (informal). Keep new comments/copy in Spanish; keep identifiers in English.
